📖 How to Use the Search Feature

This interactive robotics book includes a powerful search feature to help you quickly find topics, concepts, and code examples.

🔍 Quick Access​

There are three ways to open the search:

  1. Click the Search Bar in the top navigation
  2. Press Ctrl + K (Windows/Linux) or Cmd + K** (Mac)
  3. Press Ctrl + / as an alternative shortcut

🎯 Search Capabilities​

The search indexes everything in the book:

✅ Chapter titles and headings
✅ Body content and paragraphs
✅ Code snippets and examples
✅ Sidebar labels and navigation
✅ Page descriptions and metadata

💡 Search Tips​

Simple Search​

Just type your query and press Enter:

  • "servo motor" - Find all mentions of servo motors
  • "ROS2" - Find ROS2-related content
  • "python class" - Find Python class examples

Search Whole Book vs Current Page​

By default, search looks through the entire book.

To narrow your search:

  1. Open search with Ctrl+K
  2. Type your query
  3. Results show breadcrumbs indicating which chapter each result is from
  4. Click any result to jump to that page

Search Results Features​

Each search result shows:

  • 📄 Page title where the match was found
  • 🗂️ Breadcrumb trail (e.g., Learn → Foundations → Chapter 3)
  • ✨ Highlighted matches in yellow
  • 📝 Context snippet showing surrounding text

Keyboard Navigation​

Once search is open:

  • ↓ / ↑ - Navigate through results
  • Enter - Open selected result
  • Esc - Close search modal

🚀 Pro Tips​

1. Use Specific Terms​

Instead of: "motor"
Try: "servo motor PWM"

2. Search for Code​

The search indexes code blocks, so you can search for:

  • Function names: def setup()
  • Keywords: import rospy
  • Variables: sensor_data

3. Find Diagrams​

Search for diagram-related terms:

  • "architecture diagram"
  • "control flow"
  • "state machine"

4. Quick Topic Lookup​

Search shortcuts for common topics:

  • "basics" - Foundation chapters
  • "sensors" - Sensor-related content
  • "assignment" - Practice exercises

📱 Mobile Search​

On mobile devices:

  • Tap the search icon (🔍) in the top navigation
  • The keyboard shortcuts are hidden on small screens
  • Search works the same way as on desktop

🎨 Search Highlighting​

After navigating to a page from search results:

  • Matched terms are highlighted in yellow
  • Scroll to see all highlighted matches
  • Highlighting helps you quickly locate the exact information

❓ Common Use Cases​

Finding a Specific Topic​

Scenario: You want to learn about PID controllers

  1. Press Ctrl+K
  2. Type: PID controller
  3. Browse results from different chapters
  4. Click the most relevant result

Looking for Code Examples​

Scenario: You need a Python code example

  1. Press Ctrl+K
  2. Type: python code
  3. Look for results with code snippets in the preview
  4. Jump to the page with the example

Reviewing a Concept​

Scenario: You're on Chapter 5 but need to review something from Chapter 2

  1. Press Ctrl+K (works from any page)
  2. Type the concept name
  3. See breadcrumbs showing "Chapter 2"
  4. Click to jump directly there

🔧 Advanced Features​

Search Index​

  • The search index is generated at build time
  • Contains ~600KB of searchable content
  • Works offline once the page is loaded
  • No external services required

Privacy​

  • All search is local (runs in your browser)
  • No search queries are sent to external servers
  • No tracking or analytics on searches

🆘 Troubleshooting​

Search not working?​

  1. Refresh the page (Ctrl+R)
  2. Clear browser cache
  3. Make sure JavaScript is enabled

No results found?​

  1. Try shorter, more general terms
  2. Check spelling
  3. Try synonyms (e.g., "AI" instead of "Artificial Intelligence")

Happy Learning! 🎓

Now you can efficiently navigate the entire robotics book and find exactly what you need in seconds.
